# Банковская система — продолжение с версии Claude

С 27.11.2026 пользователь выбрал новую рабочую основу: пояснительную записку Claude.
Дальнейшая задача — небольшие адресные исправления по двум новым голосовым
комментариям преподавателя. Файл этой записки и два комментария пока не идентифицированы.

**Начать с [актуального контекста](CONTEXT.md).** Полная локальная папка IT содержит
ГОСТы, образцы, аудио и историю; не все эти файлы публикуются в GitHub.
Для переноса на Mac пользователь архивирует всю папку IT.

Документы в `Готовая работа/`, существующие генераторы и предыдущие аудиты относятся
к версии Codex от 24.11.2026. Это справочный материал, не активная версия Claude.
Не запускать пересборку прежнего отчёта вместо редактирования Claude.

Предыдущий README с картой кода, командами и файлами сохранён целиком:
[история версии Codex](docs/README_CODEX_BEFORE_CLAUDE_2026-11-27.md).

Также получено дополнение с Mac — коммит 3324ac7 (Чен, определения архитектуры, 47 страниц). Его документы и исходники сохранены без переработки. Справочные команды Mac: [README той версии](docs/README_REMOTE_BEFORE_HANDOFF_2026-11-27.md). Это ещё не идентификация новой основы Claude.
