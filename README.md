# БанкПеревод

Система учёта и контроля внутрибанковских переводов физических лиц для
операционного подразделения банка.

Репозиторий содержит готовую пояснительную записку, материалы для защиты и
воспроизводимые исходники графических моделей. Технический проект описывает
подготовку поручений, проведение переводов, полный возврат, выписки, отчёты,
контроль остатков и аудит действий сотрудников.

## Содержание проекта

Графическая часть включает ER-модели Чена предметной области и оценивания
качества, логические диаграммы со всеми 17 внешними ключами, DFD, дерево
функций, BPMN, состояния поручения, схемы алгоритмов, конкурентное
взаимодействие и архитектурные представления.

Программа и методика испытаний задают контрольные данные, действия,
ожидаемые результаты и правила приёмки. Состояние реализации — технический
проект: фактические испытания банковского программного комплекса выполняются
после реализации. Проверки в этом репозитории относятся к документации,
генераторам схем и расчёту эталонов.

## Воспроизведение схем

Используются Python 3.12+, Node.js 22+ и шрифты Arial и Times New Roman.
Готовые скрипты настроены на пути шрифтов Windows. Для другой ОС пути нужно
изменить в `draw_figures.py` и `svg_primitives.py`.

В PowerShell из корня репозитория:

```powershell
python -m pip install -r requirements.txt
npm install
Set-Location 'Готовая работа/Исходники схем'
python draw_figures.py
node render_figures.mjs ./figures
python validate_project.py
```

Зависимости зафиксированы по версиям, использованным при подготовке файлов.
Для совпадения хешей изображений нужны те же версии инструментов, шрифтов и
условия генерации. Повторная генерация на исходной машине дала совпадение
всех SVG, PNG и DOT.

Для сборки DOCX выполнить `python build_documents.py` из папки исходников.
Команда перезаписывает два документа в папке «Готовая работа». После сборки
следует обновить содержание и поля в Word и проверить страницы.
