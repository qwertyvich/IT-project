# Исходники БанкПеревод

Исправленная версия: реальная предметная область операционного подразделения банка.
В графических приложениях только диаграммы; таблицы требований и испытаний — в
основной части. Папка не содержит рабочее банковское приложение или вымышленные
протоколы его испытаний.

## Состав

- project_model.py — 9 предметных отношений и аудит, 23 требования, 13 правил,
  8 запросов и 20 сценариев испытаний.
- diagram_catalog.py — порядок, подписи и форматы 26 рисунков.
- draw_figures.py — графы Чена, логические связи, DFD, BPMN, состояния и архитектура.
- svg_primitives.py — геометрические примитивы SVG и схемы двух алгоритмов.
- render_figures.mjs — компоновка DOT через Graphviz (@viz-js/viz) и SVG → PNG (sharp).
- figures/ — 26 SVG, 26 PNG и 10 исходных графов DOT.
- figures_manifest.json — размеры, форматы А4/А3, минимальные кегли и SHA-256.
- foreign_keys.json — все 17 внешних ключей, изображённых на логических диаграммах.
- build_documents.py — сборка пояснительной записки и памятки DOCX.
- render_word.ps1 — обновление содержания и скрытый экспорт через Microsoft Word.
- validate_project.py — проверка модели, состава документов, изображений и эталонов.
- Проверка проекта.json — результаты структурной проверки; программные испытания
  банковского комплекса этими проверками не подменяются.
- Нормативная проверка.md — какие положения и нотации применены.

## Пересоздать схемы на этом компьютере

В PowerShell из этой папки выполнить:

```powershell
& .\rebuild_figures.ps1
```

Используются Python и Node из runtime Codex, Times New Roman и Arial из Windows.
Скрипт пересоздаёт схемы и манифест, не переписывая документы. Для точного
совпадения PNG нужны те же версии Graphviz, sharp и шрифтов.

## Запуск в другой среде

Нужны Python 3.12+, Pillow, python-docx, lxml, pypdf, Node.js,
пакеты sharp и @viz-js/viz, установленные шрифты Arial и Times New Roman.
Пути шрифтов для другой ОС задаются в draw_figures.py и svg_primitives.py.

```powershell
python draw_figures.py
node render_figures.mjs .\figures
python build_documents.py
python validate_project.py
```

Сборщик документов перезаписывает два одноимённых DOCX в родительской папке.
После сборки нужно обновить содержание и поля Word и выполнить постраничную
визуальную проверку. PDF из экспорта использовались для проверки и не входят в
сдаваемый комплект. Оригинальная записка другой группы сохранена без изменений.

## Независимые контрольные вычисления

Перевод 2500 руб. при A=10 000 и B=1000 даёт A=7500 и B=3500. Полный возврат
восстанавливает начальные остатки. Общая сумма остаётся 11 000. Из двух списаний
по 7000 при 10 000 проходит только одно в обоих последовательных порядках;
остаток 3000. Доля одного completed среди трёх поручений — 33,33 %.
Эти расчёты задают эталоны ПМИ, а не результаты запуска PostgreSQL-функций.
